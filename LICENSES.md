# Dataset licensing and attribution notes

The project code and dataset terms are separate. This repository does not redistribute the downloaded datasets.

- SLPL/naab: Hugging Face dataset card currently displays MIT. Its card describes a compilation of multiple corpora and warns that personal information may be present; review upstream sources and applicable terms.
- FineWeb2-HQ Persian: Hugging Face card currently displays ODC-BY; retain attribution and review the license text.
- ParsiAI/FarsInstruct: Hugging Face card currently displays Apache-2.0.
- PersianML/persian-general-knowledge: Hugging Face card currently displays CC-BY-4.0.
- Kamyar-zeinalipour/CS_Farsi: Hugging Face card currently displays CC-BY-SA-4.0.

The Persian-SFT-102K aggregate is intentionally not ingested automatically because its card says the aggregate is source-dependent and does not have one blanket license for every sample. Verify upstream terms before adding any source.

License metadata can change. Check each official dataset card and upstream source at the time of use. This file is not legal advice.
