# منابع داده و ثبت منشأ

منابع فعال در اسکریپت آماده‌سازی:

1. `SLPL/naab` — متن عمومی فارسی برای Pretraining. کارت Hugging Face فعلی MIT را نشان می‌دهد؛ به دلیل ماهیت تجمیعی و هشدارهای خود کارت درباره داده‌های شخصی، منشأ و مجوز اجزای upstream باید بررسی شود.
2. `mohammadkrb/fineweb2-HQ-persian` — زیرمجموعه فارسی FineWeb2-HQ؛ کارت فعلی ODC-BY را نشان می‌دهد.
3. `ParsiAI/FarsInstruct` — داده دستورمحور فارسی؛ کارت فعلی Apache-2.0 را نشان می‌دهد.
4. `PersianML/persian-general-knowledge` — مکالمات چندمرحله‌ای؛ کارت فعلی CC-BY-4.0 را نشان می‌دهد.
5. `Kamyar-zeinalipour/CS_Farsi` — FarSense/commonsense reasoning؛ کارت فعلی CC-BY-SA-4.0 را نشان می‌دهد.

`Persian-SFT-102K` به‌طور پیش‌فرض وارد pipeline نمی‌شود، زیرا کارت آن مجوز یکپارچه‌ای برای کل مجموعه اعلام نمی‌کند و مجوز به منبع هر نمونه وابسته است.

همه مجوزها ممکن است در آینده تغییر کنند. پیش از هر انتشار یا استفاده تجاری، صفحه رسمی دیتاست و مجوز upstream را دوباره بررسی کنید. فایل `data/public/data_manifest.json` منابع فعال را ثبت می‌کند.
